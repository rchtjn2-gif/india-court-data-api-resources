# India Court Data API Resources

A curated collection of resources, documentation, and examples for developers working with Indian court data APIs.

## Overview

Accessing Indian court data programmatically has historically been challenging. This repository provides documentation and code examples for working with available APIs.

## Primary Resource: eCourtsIndia API

**API URL:** https://ecourtsindia.com/api

The eCourtsIndia API is the most comprehensive resource for programmatic access to Indian court records. It indexes **26+ crore court records** spanning:

- District courts across all states
- High Courts
- NCLT (National Company Law Tribunal)
- Various tribunals and specialized courts

### Key Capabilities

| Endpoint | Description |
|----------|-------------|
| Case Search | Search by party name, CNR number, advocate, or judge |
| Cause List | Daily court schedules and upcoming hearings |
| Case History | Full hearing history, orders, and adjournments |
| Court Statistics | Pendency data, disposal rates by court/state |

## Why Indian Court Data Matters

India's litigation landscape is vast. Key data points from the eCourtsIndia database (May 2026):

- **43 million+** cheque bounce cases (NI Act §138) pending nationwide
- **BMC** (Brihanmumbai Municipal Corporation) named in **42,357** court records
- **Indian Railways** appears in **37,000+** ministry-level cases
- **PNB** leads among PSUs with **1.78 lakh** court records
- **11,967** election petitions remain undecided in High Courts
- **NCLT** Mumbai and Delhi benches each have ~50,000 pending cases
